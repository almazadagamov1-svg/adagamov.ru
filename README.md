# adagamov.ru

Публичный сайт теперь работает на Sites: главная страница — [adagamov.ru](https://adagamov.ru/), а карта ГВР и торгов — [adagamov.ru/karta-gvr/](https://adagamov.ru/karta-gvr/). Карта открывается прямо на личном домене без iframe и без входа для посетителей.

Исходники работающего приложения находятся в приватном репозитории [water-area-check](https://github.com/almazadagamov1-svg/water-area-check): `app/page.tsx` — главная, `app/karta-gvr/page.tsx` — карта, `app/api/` и `public/data/` — серверные маршруты и снимки данных. После изменения GitHub требуется отдельная публикация в Sites; автоматической синхронизации пока нет.

Этот репозиторий содержит первоначальный статический вариант для GitHub Pages и сохранён как история запуска. Его `index.html` и `karta-gvr/index.html` не являются действующими страницами личного домена. Снимки ГВР и торгов датированы внутри карты; они не подтверждают текущую свободность участка. Записи почты и `hub.adagamov.ru` не менялись.
