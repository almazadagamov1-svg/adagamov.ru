# adagamov.ru

Публичный статический сайт. Исходники и опубликованные файлы находятся в этом репозитории. Главная страница — `index.html`, будущая карта — `karta-gvr/index.html`. На сайте нет входа, форм и закрытых данных.

Публикация: GitHub Pages из ветки `main`, каталог `/` с пользовательским доменом `adagamov.ru`. После изменения `main` GitHub обновляет сайт автоматически.

Важно: `karta-gvr/` сейчас содержит честное сообщение об отсутствии опубликованных данных. Добавлять геоданные следует только после проверки источника, актуальности и допустимости публикации.

DNS корневого домена направляется на GitHub Pages. Записи для `hub.adagamov.ru`, почты и подтверждения владения доменом не меняются.
