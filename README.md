# adagamov.ru

Публичный сайт Алмаза Адагамова: главная страница и карта по адресу `/karta-gvr/`. Доступ без регистрации. Публикация через GitHub Pages и GitHub Actions.

Исходный проект карты хранится в закрытом репозитории `almazadagamov1-svg/water-area-check`. В этом репозитории находится только проверенная статическая сборка. Части архива `release/pages-release.part-*` склеиваются в порядке имён; `release/pages-release.sha256` проверяет результат. Workflow распаковывает релиз, проверяет содержимое и публикует его на Pages после каждого изменения релиза в `main`.

Снимок ГВР: 24.09.2026 (50 202 интерактивных объектов); торги: 30.09.2026 (236 лотов). Эти даты не подтверждают актуальность прав и торгов на день просмотра. Границы, расчётные объекты и непространственные ориентиры в карте разделены.

Публичная сборка исключает служебный корпус материалов торгов. Изменения исходного проекта требуют новой статической сборки и обновления архива релиза.

Статусы торгов обновлены по двум переданным официальным Excel-выгрузкам: 167 лотов «Приём заявок» и 69 «Определение победителя». Дубликаты объединены по официальному ID; завершённые лоты исключены. Полнота выгрузки не сверена с API. Даты проверки статуса и источника геометрии указаны отдельно.
