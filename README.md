# adagamov.ru

Публичный сайт на GitHub Pages. Главная страница — `index.html`; адрес карты — `karta-gvr/index.html`. Вход для посетителей не требуется.

Карта ГВР и торгов разработана в отдельном приватном репозитории [water-area-check](https://github.com/almazadagamov1-svg/water-area-check). Это приложение с серверными маршрутами: GitHub Pages не запускает его сервер. По адресу `/karta-gvr/` на личном домене встроен действующий публичный экземпляр приложения `https://water-area-check.almazadagamov1.chatgpt.site/`. Снимки данных датированы внутри карты, их нельзя считать актуальными без новой проверки.

Этот репозиторий автоматически публикует главную и оболочку карты из ветки `main` через GitHub Pages с доменом `adagamov.ru`. Изменения самого приложения и данных выпускаются отдельно из `water-area-check`; коммит в нём сам по себе не обновляет публичный экземпляр.

DNS корневого домена указывает на GitHub Pages. Записи `hub.adagamov.ru` и почты не менялись.
