# adagamov.ru

Публичный сайт Алмаза Адагамова: главная страница и карта по адресу `/karta-gvr/`. Доступ без регистрации. Публикация через GitHub Pages и GitHub Actions.

Исходный проект карты хранится в закрытом репозитории `almazadagamov1-svg/water-area-check`. Здесь находится только проверенная статическая сборка. Части `release/pages-release.part-*` склеиваются по имени и проверяются по `release/pages-release.sha256`. Workflow публикует их на Pages после изменения релиза в `main`.

Снимок ГВР: 24.09.2026 — 50 202 объекта. Снимок торгов: 01.10.2026 — 228 активных лотов из 35 регионов: 162 «Приём заявок» и 66 «Определение победителя». Даты снимков не подтверждают актуальность прав и торгов на день просмотра; сроки подачи заявок оцениваются отдельно.

Полностью обработана заданная выборка из 236 сохранённых официальных карточек и 608 документов. Восемь лотов со свежим статусом FAILED исключены из текущего слоя. На карте 22 подтверждённые геометрии, 103 записи с кандидатными координатами и 103 записи без безопасной геометрии. Кандидаты отображаются без пространственного утверждения. Полнота федерального реестра не подтверждена.

Публичная сборка исключает служебные документы, исходные карточки, рабочие архивы и закрытые KML/KMZ. Текущий выпуск: `bdcac93a3dd0c331`. Подтверждённые границы, расчётные объекты и непространственные ориентиры разделены.
